## URL-Chat  

URL-Chat is a Python-based application that allows users to input an OpenAI API key and a URL. The program then parses the content of the given URL, enabling interactive conversations based on its extracted data.  

This project was created before ChatGPT implemented similar functionality on its website and was later uploaded to GitHub.  

### 🚀 Features  
- Parses web content from a given URL  
- Enables interactive Q&A based on the extracted data  
- Uses OpenAI's API for conversational capabilities  

### 🔧 Installation & Setup  

1. **Clone the repository**  
   ```bash
   git clone https://github.com/Mayank-MSJ-Singh/URL-Chat.git
   cd URL-Chat
   ```  

2. **Install dependencies**  
   ```bash
   pip install -r requirements.txt
   ```  

3. **Set up your OpenAI API key**  
   - Get an API key from [OpenAI](https://platform.openai.com/signup/).  
   - Add your API key in the required section of the script.  

### ⚡ Usage  

Run the script and input the URL you want to analyze:  
```bash
python main.py
```  

You'll be able to chat with the extracted content from the given URL.  

### 🛠 Requirements  
- Python 3.x  
- OpenAI API key  
- Required Python libraries (see `requirements.txt`)
